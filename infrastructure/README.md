## Infrastructure

This folder contains the full infrastructure setup for the broader Starter Architecture workflow.

It includes:

- the local development environment
- Terraform provisioning for the initial infrastructure setup
- Ansible provisioning and configuration for the application host and Jenkins server
- CI/CD support for building and deploying multiple Starter Architecture projects

This workflow is intended for the broader `infrastructure` setup and is better suited to managing multiple projects based on the Starter boilerplate.
